# Spoonerism Data Dump

A list of about 1,500 spoonerisms, built up over many years by a compulsive spooneriser 😁

If you don't know what a spoonerism is, read about it on [Wikipedia](https://en.wikipedia.org/wiki/Spoonerism).

## Demo

https://zzalsjr8.github.io/projects/spoonerisms/

## Files

- `index.html` - HTML page to view spoonerisms in table-format - from there, sort, filter or export data.
  - Data files:
    - `spoonerisms.csv` - data in CSV format.
    - `spoonerisms.js` - data in javascript format - this file is linked to from the HTML file, and is used to populate the data table.
    - `spoonerisms.min.js` - data in javascript format, with line-breaks, tabs and multiple spaces removed.
    - `spoonerisms.json` - data in JSON format.
    - `spoonerisms.xlsx` - data in Excel format.
